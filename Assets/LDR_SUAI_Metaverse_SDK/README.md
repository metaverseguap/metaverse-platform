# Digital reality lab Software Development Kit
Данный модуль передается сторонним разработчикам. При помощи инструментов из данного модуля, сторонние разработчики могут создавать дополнительный контент для SUAI-Metaverse.
Дополнительный контент реализуемый при помощи данных инструментов автоматически встраивается в исходный проект.

Элементы данного модуля полностью автономны и не имеют зависимостей от SUAI-Metaverse, что обеспечивает возможность их передачи сторонним разработчикам,
без необходимости раскрытия исходного кода всего проекта.
