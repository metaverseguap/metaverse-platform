# Digital reality lab Software Development Kit
Данные скрипты передаются сторонним разработчикам с требованием реализовать их в своем проекте.
Данные скрипты не имеют зависимостей, для легкого встраивания в сторонние проекты.
Если объекты из сторонних проектов реализуют данные скрипты, то, при подключении объектов в платформу, эти объекты должны автоматически включиться в ее экосистему.
