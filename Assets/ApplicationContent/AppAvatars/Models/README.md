# Требования к Asset Bundle аватара
- сам Asset Bundle должен называться name_device. *Вместо name - название персонажа. Название должно быть уникальным. Вместо device - название устройства, для которого собран assetbundle (pc или pico). все названия должны быть в нижнем регистре без пробелов*
- Asset Bundle должен состоять из одного объекта - fbx модели. Модель должна иметь аниматор с гуманоидным скелетом.
- fbx должен быть не только отмечен как Asset Bundle, но так же на него должен быть добавлен label "Avatar"

# Сборка ассетов
В меню Asset есть пункт `Build Asset Bundle` -> `Avatar`. В нем появляются все Bundle помеченные label "Avatar". 



Выберите нужный ассет из списка и нажмите Создать Bundle. Bundle соберется в папку "metaverse-platform\Bundles".
Дальше можно загрузить его через меню администратора приложения либо через Swagger файлового сервера, используя endpoint `/api/avatar/file/{name}`
