# Модуль аватаров
В данном модуле находятся модели аватаров и их ресурсы.

Модели аватаров хранятся в папке `Models`. Каждая модель хранится в отдельной папке со всеми своими ресурсами. 
Вместе с моделью аватара хранится изображение аватара в формате .jpg или .png. Изображение аватара имеет имя соответствующее шаблону: "*имя_аватара*Icon".
Модели аватаров, имеют AssetBundle имя и Label `Avatar`.

Так же в данном модуле хранится логика обработки аватаров.
