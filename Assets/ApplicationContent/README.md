# ApplicationContent
Данная папка содержит основную логику проекта, организованную в виде отдельных модулей. 
Каждый модуль отвечает за определённый аспект работы приложения.

Структура папки построена модульно, что упрощает поддержку и расширение проекта. 
Новые функции рекомендуется размещать в виде отдельных модулей или внутри уже существующих, если они соответствуют их ответственности.

## Папка `Editor`
Папка `Editor` предназначена для скриптов, работающих только в среде Unity Editor. 
Эти скрипты используются для автоматизации процессов разработки, настройки компонентов, генерации данных и других задач, 
которые не включаются в финальную сборку приложения.

## Модули проекта

Внутри `ApplicationContent` расположены следующие модули:
- `AppAvatars` — модели аватаров и логика их обработки;
- `Chat` — модуль сетевого чата;
- `EmbeddedScenes` — сцены, интегрированные в платформу;
- `Global` — общие утилиты и глобальные компоненты, используемые во всём проекте;
- `Localization` — система локализации интерфейса и контента;
- `MainMenu` — главное меню приложения. Стартовая точка запуска приложения в сетевом режиме. Логика загрузки Asset Bundle;
- `Microphone` — модуль взаимодействия с микрофоном;
- `NetworkCore` — сетевой модуль;
- `OfflineScene` — сцена, в которую игрок попадает после авторизации и подключения к сети;
- `Player` — контроллеры игрока;
- `UserSystem` — модуль пользователей и ролей.
