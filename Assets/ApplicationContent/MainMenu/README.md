# Main menu
Модуль главного меню содержит главное меню платформы. Это меню является стартовой точкой платформы. 
Для запуска платформы в многопользовательском режиме, запустите сцену `MainMenu/Scene/01_AuthMenu.unity`.
В данной сцене так же присутствует объект `NetworkManager`, содержащий компонент сетевых настроек.

Так же данный модуль содержит логику загрузки Asset Bundle аватаров в сцене `MainMenu/Scene/02_AvatarLoading.unity` (компонент `UIAvatarLoadingMenu`)
и логику загрузки Asset Bundle сцен в сцене `MainMenu/Scene/05_IntermediateLoadingScene.unity` (компонент `UISceneLoadingMenu`).
В сцену `MainMenu/Scene/05_IntermediateLoadingScene.unity` пользователь попадает при смене комнаты в сети. 
В данной сцене проверяется нужно ли загружать сцену, к которой подключается пользователь. 
При необходимости происходит загрузка сцены и подключения пользователя к ней.

На текущем этапе модуль имеет сильную зависимость от модуля `NetworkCore`. 
По контракту считается, что модуль `NetworkCore` всегда доступен в данном модуле, а компонент `MVNetworkManager` всегда присутствует в сцене.
На текущем этапе, модуль не предлагает возможностей офлайн работы - для его работы требуется подключение к файловому серверу.
