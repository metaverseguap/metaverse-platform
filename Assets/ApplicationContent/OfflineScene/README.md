# Offline scene
В данном модуле хранится сцена, в которую игрок попадает после авторизации и подключения к сети.

В данную сцену пользователь подключается как хост, но к нему в комнату не могут подключиться другие пользователи.

В отличие от `Embedded Scenes` данная сцена добавляется в Build проекта.
