# Server Interaction
Модуль взаимодействия с файловым сервером.

Файловый сервер представляет собой REST архитектуру, предоставляющую доступ к своим Endpoint-ам.
В данном модуле расположены объекты хранения данных запросов к файловому серверу и ответов от него,
а так же сервисы осуществляющие запросы на файловый сервер.

Объекты хранения данных находятся в пространстве имен `NetworkCore.ServerInteraction.Type`.

За осуществление http запросов на файловый сервер отвечает класс `RestAPI`.
Класс `AbstractServerAPI` хранит в себе экземпляр `RestAPI`, для того что бы реализации сервисов запросов к различным endpoint-ам могли его использовать.
Классы, отправляющие конкретные запросы на определенные endpoint-ы являются потомками `AbstractServerAPI`.
Точкой доступа ко всем существующим сервисам запросов является класс `APIContainer`.
Классы, осуществляющие запросы к файловому серверу хранятся в пространстве имен `NetworkCore.ServerInteraction.API`.
