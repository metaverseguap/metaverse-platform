# Embedded Scenes
Сцены, интегрированные в платформу.

Данные сцены не добавляются в Build проекта, а загружаются в Runtime с файлового сервера.
Если сцена не содержит собственных скриптов (не считая скриптов `LDR_SUAI_Metaverse_SDK`),
то такую сцену можно добавить в платформу простой загрузкой ее Bundle на файловый сервер - без необходимости повторной сборки клиентов.

Каждая сцена находится в отдельной папке. Сцены имеют зависимости от `LDR_SUAI_Metaverse_SDK`, потому что они были разработаны с его помощью,
но все остальные зависимости сцены находятся внутри папки сцены.

Каждая сцена имеет изображение в формате .png или .jpg. Имя изображения сцены формируется согласно шаблону "*имя_сцены*Icon".

Файл сцены `.unity` имеет имя AssetBundle.
Asset Bundle должен называться name_device. *Вместо name - название сцены. 
Название должно быть уникальным. Вместо device - название устройства, для которого собран assetbundle (pc или pico). 
Все названия должны быть в нижнем регистре без пробелов*

В меню Asset есть пункт `Build Asset Bundle` -> `Scene`. В нем появляются все Bundle сцен.
Выберите нужный ассет из списка и нажмите "Создать Bundle". Bundle соберется в папку "metaverse-platform\Bundles".
Дальше можно загрузить его через меню администратора приложения либо через Swagger файлового сервера, используя endpoint `/api/scenes/upload-scene`.

Сцены имеют точки спавна, а значит могут запускаться независимо через редактор Unity. В таком режиме сетевые функции будут недоступны.
По умолчанию точка спавна создает урезанную версию PC_Player. Но для Debug-а можно вручную заменить префаб игрока в свойстве точки спавна.
Это никак не повлияет на сетевой режим сцены, поскольку в нем точки спавна не спавнят игрока указанного в их свойствах.
