# Требования к assetbundle аватара
- сам assetbundle должен называться name_device. *Вместо name - название персонажа. Название должно быть уникальным. Вместо device - название устройства, для которого собран assetbundle (pc или pico). все названия должны быть в нижнем регистре без пробелов*
- В assetbundle должны быть включены 3 ассета: fbx персонажа, префаб, контроллер анимации
- fbx должен иметь название name
- контроллер анимации должен иметь название name
- префаб должен иметь название nameprefab
