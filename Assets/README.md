# Assets
В этой директории хранятся все основные ресурсы и исходные файлы проекта.

## Структура
### `ApplicationContent`

Содержит основной код и ресурсы приложения: сцены, скрипты, компоненты и другие элементы. 
<u>**Внимание:** **не переименовывайте** эту папку</u>! Скрипты в проекте используют её точное имя для поиска и загрузки файлов.
Переименование приведёт к сбоям в работе приложения.

### `LDR_SUAI_Metaverse_SDK`

Software Development Kit. Данный asset предназначен для сторонних разработчиков, создающих дополнительный контент, совместимый с основным приложением. 
Включает необходимые интерфейсы, шаблоны и документацию для интеграции.

### Ассеты из Asset Store

В корне папки `Assets` размещаются сторонние ассеты, импортированные из Unity Asset Store. 
Они не перемещаются в подпапки проекта, чтобы избежать проблем с путями и зависимостями. 
На текущий момент используется следующий список ассетов:
1. `Mirror` — сетевая библиотека для реализации многопользовательского взаимодействия;
2. `DatePicker for UnityUI` — ассет ui календаря для выбора даты;
3. `DOTween` — ассет динамической анимации создаваемой через код.

### Графика и рендеринг

Проект использует **Universal Render Pipeline (URP)** вместо стандартных материалов Unity. 
Это позволяет добиться более высокой производительности и гибкости при работе с графикой на различных устройствах.

---

При работе с содержимым папки `Assets` следуйте структуре и правилам именования, чтобы обеспечить стабильность и совместимость проекта.
